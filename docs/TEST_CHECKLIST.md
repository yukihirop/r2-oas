## テスト実施手順

### 1. ローカルサーバー起動
```bash
cd /Users/yukihirop/RubyProjects/r2-oas
bundle exec jekyll serve
```

### 2. ブラウザで確認
- デスクトップ: `http://localhost:4000/r2-oas/`
- モバイル: Chrome DevTools のデバイスモードを使用
- タブレット: Chrome DevTools のデバイスモードを使用

### 3. キーボードナビゲーション
- Tab キーで順番に移動
- Enter/Space キーで操作
- Escape キーで閉じる

### 4. Lighthouseスコア測定

#### 方法1: Chrome DevTools (推奨)
1. Chrome ブラウザで `http://localhost:4000/r2-oas/` を開く
2. DevTools を開く (F12 または右クリック→「検証」)
3. 「Lighthouse」タブを選択
4. カテゴリーを選択:
   - ✅ Performance
   - ✅ Accessibility
   - ✅ Best Practices
   - ✅ SEO
5. デバイスを選択: Desktop または Mobile
6. 「Analyze page load」をクリック
7. レポートを確認し、スコアを記録

#### 方法2: Lighthouse CLI (オプション)
```bash
# Lighthouse CLIをインストール (未インストールの場合)
npm install -g lighthouse

# レポート生成
lighthouse http://localhost:4000/r2-oas/ --output html --output-path ./lighthouse-report.html
```

#### 目標スコア
- **Performance**: 90+ (パフォーマンス)
- **Accessibility**: 95+ (アクセシビリティ)
- **Best Practices**: 90+ (ベストプラクティス)
- **SEO**: 100 (検索エンジン最適化)

#### テスト対象ページ
- トップページ: `/r2-oas/`
- 主要セクション: `/r2-oas/usage/`, `/r2-oas/configuration/`
- コンテンツページ例: `/r2-oas/usage/use-plugins/`
